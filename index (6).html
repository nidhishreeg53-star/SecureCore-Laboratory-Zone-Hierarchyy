DFS (depth-first)

Goes as deep as possible down one branch before returning to try another. Uses recursion or a stack.

BFS (breadth-first)

Visits the tree level by level, using a queue. It reaches the shallowest match first.

In a general tree, zone names have no order, so both searches may examine every node: O(n) worst case, where n is the number of nodes. A BST differs because its ordered keys let each comparison discard one side.
